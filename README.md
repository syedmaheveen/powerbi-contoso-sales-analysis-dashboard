# Contoso Sales Analysis

## About the Project

This project analyzes Contoso sales data to understand sales performance, customer behavior, product performance, and regional sales.

## Tools Used

* Microsoft Excel
* SQL
* Power BI

## Analysis

* Sales Analysis
* Product Analysis
* Customer Analysis
* Regional Analysis
* Sales Trend Analysis

## Dashboard

A Power BI dashboard was created to visualize important sales metrics and business insights.

## Objective

To analyze sales data and identify useful business insights that can support better decision-making.
